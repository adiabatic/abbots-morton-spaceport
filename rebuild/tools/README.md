# Rebuild tools

Long-running scripts for the M1 rebuild. All run from the repo root (some import `rebuild.pipeline`, so use `PYTHONPATH=. uv run python rebuild/tools/<script>.py` where the docstring says so).

| Script                 | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `artifact_cycle.py`    | The commit-time artifact cycle (`make artifact-cycle`): snapshot, `run_m1`, surface rebuild, verdict carry and merge, echo/standing fills, census refresh, complaints, gates; stages skip on unchanged inputs — the whole verdict-plumbing chain, snapshot included, on one key over the surface, master, store, and standing approvals — and `--defer-gates` leaves the heavy gates to the next pass when this one rebuilt anything               |
| `carry_verdicts.py`    | Re-resolves prior verdict exports against the surfaces they were recorded on and carries render-identical units onto the live review surface                                                                                                                                                                                                                                                                                                       |
| `complaint_docket.py`  | Clusters open reject/neither verdicts by the deciding rune records, with park candidates for the still-blank lookalikes; `--park` emits a `verdicts-park-*.json`                                                                                                                                                                                                                                                                                   |
| `deep_sweep.py`        | The periodic deep form of gate:conform (`make conform-deep`): the exhaustive font-vs-settle sweep at horizon 5+, green-keyed on the emitted lookup's behavior classes plus the font-compilation code and the uharfbuzz version, so rune edits that introduce no novel rule shape never stale it; `--status` asks whether it is armed                                                                                                               |
| `echo_verdicts.py`     | Emits fill records for blank units in agreeing echo groups (`review_docket.verdicts_agree`, which reads an approve/identical mix as one voice) and prints every group whose recorded verdicts disagree, each with a `#units=` deep-link                                                                                                                                                                                                            |
| `review_docket.py`     | Writes tmp/docket-data.json (blank clusters by shard `cluster` signature, ruled classes, disagreeing echo groups) for bulk proposals; the live view is `#view=docket`                                                                                                                                                                                                                                                                              |
| `scratch_build.py`     | Parameterized `load_spec(runes_dir, ...)` build into a scratch out-dir, for A/B oracle experiments without touching `glyph_data/runes/`                                                                                                                                                                                                                                                                                                            |
| `standing_verdicts.py` | Emits fill records for blank units matching the checked-in standing approvals (`rebuild/standing-approvals.yaml`); a rule's `except_left` families still queue; two rules may also explain one window between them, at the rendered-pixel grain, when neither reaches it alone                                                                                                                                                                     |
| `probe.py`             | Probe one codepoint window: old-font baseline vs new settlement, all configs                                                                                                                                                                                                                                                                                                                                                                       |
| `verdict_ready.py`     | The readiness checklist (`make verdict-ready`): surface freshness by input fingerprint, gate greenness from the last cycle, verdict-store alignment, server, blanks                                                                                                                                                                                                                                                                                |
